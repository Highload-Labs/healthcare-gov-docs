# HealthCareGov Reconstruction
An SSDLC-driven reconstruction project inspired by lessons learned from the 2013 HealthCare.gov failure, focusing on scalability, reliability, and iterative system hardening under high concurrency.

## Objective
- Learning and Implementing SSDLC of Iterative Agile
- Target: 250,000 Concurrent Users
- Tech Stack: Go, AWS, Terraform, k6
