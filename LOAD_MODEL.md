# Load Model

## Objective
Simulate burst authentication and session traffic patterns to evaluate system behavior under high-concurrency spike conditions.

## Load Type
- Spike Testing
- Distributed load generation using k6

## Virtual User Targets
- Baseline: 10,000 VUs
- Intermediate Targets: 50,000 / 100,000 VUs
- Spike Target: 250,000 VUs

## Traffic Distribution
- 70% Session/User data retrieval
- 20% Login requests
- 10% Registration requests

## User Behavior
- Users may remain idle between requests
- Requests are not continuously generated by each VUs

## Load Generation Strategy
- Distributed k6 workers
- Horizontal scaling of load generators

## Metrics Collected
- Request rate (RPS)
- p50 / p95 / p99 latency
- Error rate
- CPU / Memory usage
